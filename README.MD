# Test task for ITK academy
Это тестовое задание для ITK academy. Условия задания лежат в папке task.

# Как использовать

Запуск (windows) ``` ./app.bat --start [-b]``` Флаг -b для форсированной сборки образа после изменений

Запуск (linux) ``` ./app.sh --start [-b]``` Флаг -b для форсированной сборки образа после изменений

Перезапуск (windows) ``` ./app.bat --restart [-b]``` Флаг -b для форсированной сборки образа после изменений

Перезапуск (linux) ``` ./app.sh --restart [-b]``` Флаг -b для форсированной сборки образа после изменений

Выключить (windows) ``` ./app.bat --stop ```

Выключить (linux) ``` ./app.sh --stop ```

# Мои догадки и изменения тз

1. Очепятка в типовом json'e запроса на изменения. Исправил очепятку в запросе.

```json
{
    valletId: UUID, --> walletId
    operationType: DEPOSIT or WITHDRAW,
    amount: 1000
}
```

2. У запроса на получение и у запроса на изменение кошелька разный апи адрес, хотя это не имеет 
смысловой нагрузки, тк это Read и Update операции над базой данных кошельков.

``` POST api/v1/wallet ``` 
``` GET api/v1/wallets/{WALLET_UUID} ```

Потому изменил адрес апи операции изменения кошелька на ``` api/v1/wallets ```. В дальнейшем это будет иметь больше смысла для расширения функций апи.

3. Из-за новых рекомендаций по использованию монтажа папок к postgres, добавление самой папки слишком сильно увеличивает вес репозитория.
