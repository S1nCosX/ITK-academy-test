# Test task for ITK academy
Это тестовое задание для ITK academy. Условия задания лежат в папке task.

# Как использовать

Запуск (windows) ``` ./app.bat --start [-b]``` Флаг -b для форсированной сборки образа после изменений

Запуск (linux) ``` ./app.sh --start [-b]``` Флаг -b для форсированной сборки образа после изменений

Перезапуск (windows) ``` ./app.bat --restart [-b]``` Флаг -b для форсированной сборки образа после изменений

Перезапуск (linux) ``` ./app.sh --restart [-b]``` Флаг -b для форсированной сборки образа после изменений

Выключить (windows) ``` ./app.bat --stop ```

Выключить (linux) ``` ./app.sh --stop ```
